# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [Unreleased]

### Added

- Initial project setup with Next.js web application and React Native mobile application
- Professional GitHub repository structure with issue templates and contribution guidelines
- Comprehensive documentation for Web and Mobile applications

### Security

- Implemented HMAC-based cryptographic signing for QR codes
- Added Row Level Security (RLS) policies for Supabase tables
- Configured HTTP-only cookies for session management

## [0.1.0] - 2024-12-27

### Added

- **Web Application**:
  - Super Admin dashboard for event monitoring
  - Student registration portal for CRs/GRs
  - Digital pass interface with animated QR codes
  - Real-time attendance tracking
- **Mobile Application**:
  - QR code scanner with entry/exit modes
  - Offline verification capability
  - Haptic feedback for scan results
